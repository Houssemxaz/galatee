# Étape 5 - Visuels et backgrounds

One job: générer trois previews visuelles pour comparer les directions avant Figma.

## Règles communes
- Format: preview homepage desktop horizontale, ratio 16:9.
- Palette principale: Olive Green / Olivenite `#313118` et Terracotta `#83482B`.
- Couleurs de support: Bancha `#6D6844`, Hillside `#CCC6A9`, Farine `#E4E0D0`, Céramique `#F1EBDD`.
- Pas de photos générées de chef, équipe, salle, façade, cuisine, clients ou scène de restaurant.
- Images autorisées: plats de menu, assiettes isolées, textures, lumière, matière, fonds abstraits, illustrations de pâtes.
- Ne pas copier les références fournies; en reprendre seulement la structure, la vibe, la densité et la lumière.

## Prompt 1 - La Table Claire

Use case: ui-mockup
Asset type: restaurant homepage design direction preview
Primary request: create a premium minimalist website homepage preview for Galatee, a fresh pasta restaurant in Hydra, Algiers.
Style/medium: high-end web design mockup, typographic, refined, sparse, editorial luxury.
Composition/framing: 16:9 desktop homepage hero and first menu hint; mostly typography and whitespace; no large photo hero; thin pasta-line motif; clear reservation CTA.
Lighting/mood: calm daylight, quiet confidence, refined hospitality.
Color palette: Olive Green / Olivenite `#313118` and Terracotta `#83482B` as the two main brand colors; Hillside, Farine and Ceramique as support surfaces; Bancha for secondary lines.
Materials/textures: fine paper grain, ceramic white, matte ink, very thin rules.
Text: minimal interface text only, with "GALATEE" as the brand name if text is used.
Constraints: no chef, no team, no restaurant interior, no facade, no kitchen, no clients; menu dish imagery only in a small lower section if needed.
Avoid: generic restaurant template, black luxury, gold palace, fake AI photos, stock food collage, blue Mediterranean clichés.

## Prompt 2 - Atelier Vivant

Use case: ui-mockup
Asset type: restaurant homepage design direction preview
Primary request: create a creative but premium website homepage preview for Galatee, based on the brand's current global creative logic but more mature and structured.
Style/medium: editorial mixed-media web design, structured asymmetry, premium illustration system.
Composition/framing: 16:9 desktop homepage with asymmetric modules, abstract pasta ribbon illustrations, menu preview cards, reservation CTA integrated clearly; creative details but still readable.
Lighting/mood: warm, crafted, lively, design-conscious, not messy.
Color palette: Olive Green / Olivenite `#313118` and Terracotta `#83482B` must be visibly primary; Hillside and Farine as paper surfaces; Bancha for secondary areas and linework.
Materials/textures: grain paper, printed ink, thin construction lines, matte ceramic, subtle illustrated pasta forms.
Text: minimal interface text only, with "GALATEE" as the brand name if text is used.
Constraints: no chef, no team, no restaurant interior, no facade, no kitchen, no clients; allow menu dishes and abstract illustrations only.
Avoid: scrapbook mess, childish pasta drawings, too many ornaments, generic Dribbble food layout, fake reportage photography.

## Prompt 3 - Soirée à Hydra

Use case: ui-mockup
Asset type: restaurant homepage design direction preview
Primary request: create a cinematic but balanced website homepage preview for Galatee, mixing the minimal elegance of La Table Claire with the creative detail of Atelier Vivant.
Style/medium: premium cinematic web design mockup, measured contrast, editorial hospitality.
Composition/framing: 16:9 desktop homepage with a composed hero, light and matter as visual focus, subtle abstract pasta gesture, one menu-dish moment, clear reservation CTA; not too dark.
Lighting/mood: evening table light, intimate, composed, premium, balanced.
Color palette: Olive Green / Olivenite `#313118` and Terracotta `#83482B` as the two main brand colors; support with Hillside, Farine, Ceramique and Bancha; no pure black.
Materials/textures: soft table-light halo, ceramic reflections, paper grain, shadow gradients, matte olive surfaces.
Text: minimal interface text only, with "GALATEE" as the brand name if text is used.
Constraints: no chef, no team, no restaurant interior, no facade, no kitchen, no clients; use menu dishes, abstract matter and light only.
Avoid: black/gold luxury, private club look, overly cinematic darkness, fake restaurant photography, AI-looking dramatic smoke.
